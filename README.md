# Freestone County ARES - Tactical Operations Mobile App (v7.4)

Tactical Operations & Field Deployment Platform for **Freestone County Amateur Radio Emergency Service (ARES)**, Texas.

EC: Brian Davis (`KG5TZT`)

---

## ⚡ Field Deployments Tonight

### 1. Direct Android APK (.apk)
* Go to the [Latest Release](../../releases/latest) in this repository.
* Download `Freestone-ARES-Tactical-v7.4.apk`.
* Tap **Install** on your Android device (enable *"Install unknown apps"* if prompted).
* Open the app: All offline maps, verified roster, NetLogger sync, and tactical tools are ready to roll.

### 2. Live Web / PWA (iOS, Android, Mac, PC)
* Visit the [Live Web App](https://freestone-ares.github.io/freestone-ares-tactical/).
* **On Android Chrome:** Tap the browser menu `⋮` and select **Install app** or **Add to Home Screen**.
* **On iPhone / iPad Safari:** Tap the **Share** button (box with up arrow) and select **Add to Home Screen**.
* **On Mac / Desktop:** Works directly in Safari, Chrome, and Edge with full offline caching.

## 🛰️ Core Tactical Capabilities
* **Offline Texas County Maps:** Pre-cached OpenStreetMap county-level tile packs for zero-connectivity blackout zones.
* **Pre-Seeded Verified Roster:** 16 Freestone County operators with passwordless 6-digit OTP verification and contact masking privacy.
* **APRS-IS & Weather Feeds:** Live tactical packet monitoring, NOAA radar overlays, and digipeater status.
* **ICS-213 & Tactical Forms:** Direct digital form generation and Winlink-compatible transmission formats.
* **Direct Field Calling:** One-touch `📞 CALL` and `💬 SMS` native OS dialer hooks.
